## Phase 1.5 — OS refinement (current focus)

**Make the existing OS feel better and more refined.** No new apps planned — refinement is the roadmap.

Refinement pass 2026-07-23 (verified with headless-Chrome screenshots across all 5 themes):

- **App Switcher rebuilt in-era** — was Aqua glass (blur, radius 16, soft shadow, direct CLAUDE.md violation); now platinum `chrome-outset` panel with navy selection that inherits every theme's bevels. Added ⌥Tab trigger (⌘Tab is OS-reserved in most browsers) and moved key handling to capture phase so Tab no longer leaks into apps (it was triggering Terminal autocomplete mid-switch).
- **Menu dropdown hover highlight was invisible on Platinum** — inline `background: transparent` on items beat the stylesheet `:hover` rule, leaving white text on white. Base background moved into `.menu-dropdown-item` CSS (also fixed in ContextMenu).
- **Menu keyboard navigation** — ↑/↓ walk enabled items (disabled skipped), Enter/Space selects, ←/→ hop between menus with wraparound, mouse hover clears the keyboard highlight. Also honored the existing "no ⌘ shortcuts while a menu is open" rule the code claimed but never enforced.
- **Spotlight fixes** — panel was visibly off-center (framer-motion's y/scale transform clobbered `translateX(-50%)`; now auto-margin centered) and the close fade never played (`return null` inside `AnimatePresence`; the presence gate now lives inside the component).
- **Theme-authentic title bars** — Windows XP/98 windows now put all controls on the right in minimize/maximize/close order with a left-aligned title; Aqua groups the traffic lights together on the left. Pure CSS (flex `order`) — no React changes.
- **Edit → Paste actually works** — browsers block `execCommand('paste')`; falls back to `navigator.clipboard.readText()` + caret insertion that fires React's onChange.
- **Smaller fidelity fixes** — dock indicator dot persists for minimized apps; menu-bar clock ticks exactly on the minute (could lag 30s); desktop icons open with Enter/Space; windows clamp back on-screen live on viewport resize (previously only on reload).

Known limitations, deliberately left: ⌘W/⌘Q are browser-reserved and may close the tab instead of the window; ⌘Tab is consumed by macOS itself (hence ⌥Tab).
